<workflow>
以下の手順を守って Oracle のデータベースオブジェクトを PostgreSQL に変換してください。
0. 変換前の前提条件チェック:
   - 対象オブジェクトの存在確認
   - 依存オブジェクト（テーブル、型、他の関数等）の洗い出し
   - 結果ディレクトリ `./result/{オブジェクト名}/` の作成
   - 前提条件の確認結果を `./result/{オブジェクト名}/prerequisites.txt` に保存
1. Oracle DB にクエリを投げて、対象となる DB オブジェクトの SQL を取得し、`./result/{オブジェクト名}/oracle.sql` に保存する
2. その SQL をよく読み込んで理解し、テスト用の SQL を `./result/{オブジェクト名}/oracle_test.sql` に保存する
3. Oracle でテストを実行して結果を確認し、`./result/{オブジェクト名}/oracle_test.txt` に保存する
4. Oracle SQL を PostgreSQL 用に変換し、`./result/{オブジェクト名}/postgres.sql` に一時保存する
5. 変換した SQL を PostgreSQL DB に対して実行し、オブジェクトを作成する
6. Oracle と全く同じテストケースを PostgreSQL 用に書き換え、`./result/{オブジェクト名}/postgres_test.sql` に保存する
7. テストコードを実行し、`./result/{オブジェクト名}/postgres_test.txt` に結果を保存する
8. Oracle の結果と比較検証する。差異がある場合は以下を実施:
   - 差異の原因を分析し、`./result/{オブジェクト名}/debug.txt` に記録
   - ステップ4に戻り、SQL を修正（最大3回まで試行）
9. テストを通過した PostgreSQL の DB オブジェクト作成 SQL を最終版として `./result/{オブジェクト名}/postgres.sql` に保存する
10. 変換結果のサマリー作成:
    - 成功した場合は `./result/{オブジェクト名}/OK.txt` を作成
    - 失敗した場合は `./result/{オブジェクト名}/NG.txt` を作成
    - サマリーには後述の <output_specification> に従った内容を記載
</workflow>
